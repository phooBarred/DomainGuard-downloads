# DomainGuard downloads

[Source code, APK downloads and new releases](https://github.com/phooBarred-Apps/DomainGuard) are now together in the public DomainGuard repository.

- [Download the latest APK](https://github.com/phooBarred-Apps/DomainGuard/releases/latest/download/DomainGuard.apk)
- [Release notes and corresponding source](https://github.com/phooBarred-Apps/DomainGuard/releases)
- [Features and installation/build instructions](https://github.com/phooBarred-Apps/DomainGuard/blob/main/README-DomainGuard.md)

This repository retains earlier releases and their corresponding source archives. Each archived APK release includes its source and checksums in the release assets.

DomainGuard is a modified GPLv3 build of [HeartGuard](https://github.com/hoodedpaladin/HeartGuard), derived from [NetGuard](https://github.com/M66B/NetGuard). Original notices and [LICENSE](LICENSE) are retained.
